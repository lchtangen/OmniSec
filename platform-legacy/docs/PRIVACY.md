# OmniSec ULTIMATE — Privacy Policy

## Our Promise
**We collect ZERO data. No telemetry. No analytics. No phone-home.**

### Data Collection
- OmniSec does NOT collect any personal data
- OmniSec does NOT use analytics services
- OmniSec does NOT phone home
- OmniSec does NOT require an account
- OmniSec does NOT track usage
- OmniSec does NOT store cookies
- OmniSec does NOT have cloud dependencies

### Network Access
- OmniSec runs 100% offline by default
- Network access is ONLY used for user-initiated operations (scanning targets the user specifies)
- No data ever leaves your device without explicit user action
- All AI processing is local (no API calls)

### Data Storage
- All configuration stored locally
- All logs stored locally
- All cached data stored locally
- User chooses what to keep or delete

### Third-Party Access
- No third-party services are contacted
- No analytics SDKs are included
- No advertising SDKs are included
- No crash reporting without explicit opt-in

### GDPR / CCPA Compliance
- Since we collect nothing, there is nothing to delete
- No data processors
- No data transfers
- No data retention policies needed

### Updates
- Updates are checked via GitHub Releases API (opt-in)
- Update check can be disabled entirely
- No update telemetry

### Contact
- For privacy concerns: team@omnisec.io
- Open an issue on GitHub for transparency
