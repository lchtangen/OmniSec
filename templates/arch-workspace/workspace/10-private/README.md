# Private Area

This directory is for personal sensitive material.

Examples:

- private notes
- credentials
- key material
- unreleased identifiers
- encrypted backups

Rules:

- Permissions must stay strict.
- Do not commit this directory.
- Prefer encrypted files with `age`, `gpg`, or another trusted tool.
