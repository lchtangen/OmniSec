# Labs

This directory is for learning experiments.

## Lab Areas

```text
wifi-adapter/          USB Wi-Fi adapter tests, chipset notes, own-network captures
networking/            WireGuard, Tor, iperf, routing, DNS tests
security-authorized/   only systems you own or have explicit permission to test
ai-agents/             Codex, local model, automation experiments
android-automation/    Android APIs, scripts, app control flows
reverse-engineering/   binary analysis and CTF-style practice
```

Keep raw wireless logs, captures, and device identifiers private.
