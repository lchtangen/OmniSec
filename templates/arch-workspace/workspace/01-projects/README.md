# Projects

Use this directory for personal projects that produce code, configs, packages, kernels, apps, or repeatable research.

## Layout

```text
active/       current work
incubator/    ideas not yet promoted
archive/      inactive but worth keeping
templates/    starter layouts
```

## Active Categories

```text
android/      Android apps, automation, APK tooling
kernel/       OnePlus 7 Pro SM8150 kernel work
nethunter/    NetHunter integration, services, custom commands
wifi/         USB Wi-Fi adapter and wireless engineering lab
arch/         Arch chroot setup and package/build automation
codex/        Codex workflows, prompts, local agent experiments
ai/           local/on-device AI experiments
security/     authorized-only security labs
```

Every project should have:

- `README.md`
- `notes.md`
- `scripts/`
- `src/` when code exists
- `artifacts/` for generated outputs worth preserving
