FREQUENTLY ASKED QUESTIONS

Is OmniSec really offline-only?

Yes. Zero cloud dependencies. Zero telemetry. Zero data collection. Everything runs locally on your hardware. No internet required for any feature. Not even for updates — everything is bundled.

Is it really free forever?

Yes. Open source, community-driven, no paywalls, no enterprise upsells. We believe cybersecurity should be accessible to everyone. Not just enterprises with six-figure budgets.

Does it run on Android?

Full support for Termux on Android. OnePlus, Pixel, Samsung — any device. Same 161 tools, same AI copilot, same mesh networking. Your phone becomes a full cyberdeck.

What AI models are supported?

Any model compatible with Ollama or llama.cpp — Llama 3, Mistral, Phi, Gemma, CodeLlama, DeepSeek. Everything runs locally. No API keys. No cloud LLMs. No data leaks.

How does mesh networking work?

Reticulum-based decentralized networking. Devices discover each other via LoRa, WiFi, or Bluetooth and form encrypted mesh networks. No internet. No infrastructure. No central server.

What platforms are supported?

Kali Linux, Ubuntu 20.04+, Arch Linux, Fedora 38+, Android (Termux), macOS 13+, Windows 10/11, WSL2. All platforms get the same 161 tools and features.
