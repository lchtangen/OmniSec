# Support

## Getting Help

- **Documentation**: See `docs/` or visit [omnisec.dev/docs](https://omnisec.dev/docs)
- **Discussions**: Use [GitHub Discussions](https://github.com/lchtangen/OmniSec/discussions) for questions
- **Issues**: Open a [bug report](https://github.com/lchtangen/OmniSec/issues/new?labels=bug&template=bug_report.md) for bugs
- **Security**: Report vulnerabilities via [SECURITY.md](SECURITY.md)

## Community

- **Discord**: [OmniSec Community](https://discord.gg/omnisec)
- **Matrix**: `#omnisec:matrix.org`
- **IRC**: `#omnisec` on Libera.Chat

## Before Opening an Issue

1. Search existing [issues](https://github.com/lchtangen/OmniSec/issues)
2. Check [discussions](https://github.com/lchtangen/OmniSec/discussions)
3. Read the [documentation](https://omnisec.dev/docs)
4. Run `make doctor` to diagnose common problems
5. Run `nhctl doctor` for device-specific diagnostics
