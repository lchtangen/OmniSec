- Primary goal: faster daily development flow
- Organization model: by platform
- Maturity labels: stable, beta, experimental
- Naming convention: UPPERCASE docs and kebab-case directories
- Repo strategy: move to centralized `repos/` hierarchy
- Documentation depth: standard
- Automation preference: bash scripts and checks

- New docs should use UPPERCASE file names where practical.
- Migration tasks should produce path mapping notes.
