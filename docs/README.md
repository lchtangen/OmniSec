# Workspace Documentation

This directory contains workspace-level documentation for the reorganized platform-first filesystem.

## Start Here

- Read `../README.md` for root-level navigation.
- Read `WORKSPACE-PROFILE.md` for personalization settings.
- Read `REPO-MIGRATION-MAP.md` for old path to new path mapping.
- Read `START-HERE-DESKTOP.md` for desktop repos.
- Read `START-HERE-MOBILE.md` for mobile repos.
- Read `START-HERE-WEB.md` for web repos.
- Read `START-HERE-EMBEDDED.md` for embedded repos.

## Structure

- `REPO-MIGRATION-MAP.md`: migration matrix from legacy paths.
- `WORKSPACE-PROFILE.md`: personal customization profile.
- `START-HERE-DESKTOP.md`: desktop platform onboarding.
- `START-HERE-MOBILE.md`: mobile platform onboarding.
- `START-HERE-WEB.md`: web platform onboarding.
- `START-HERE-EMBEDDED.md`: embedded platform onboarding.
- `../scripts/validate-workspace-structure.sh`: naming and link validation.

## Design Principles

- Centralized repositories under `repos/`
- Platform-first grouping
- Kebab-case directories
- Agent-first command workflows
