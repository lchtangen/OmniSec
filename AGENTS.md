## 4. Required Workflow for AI Agents

### 4.1 Context Gathering
1. Read `AGENTS.md` (this file) and `.github/copilot-instructions.md`
2. Run `git status` and `git log --oneline -n 5` for current state
3. Check `.github/instructions/` for scope-specific rules matching target files
4. For complex tasks, run `make ai-context` for a full repo snapshot

### 4.2 Implementation
- Edit source files only (`src/`, `scripts/`, `deploy/`, `tests/`)
- Preserve script role boundaries (host = Bash, device = POSIX sh)
- Keep changes surgical — do not refactor unrelated files
- Use `nh-defaults.sh` for configurable values
- Use `nh-lib` for device-side shared helpers

### 4.3 Validation
Always run in this order:
```bash
make lint          # Shell, C, JSON validation
make test          # BATS + C unit tests
make stage         # Regenerate payload/ if source payload files changed
```
For deploy-impacting changes, also run:
```bash
make validate      # lint + test + validate.sh
```

## 5. Agent Handoff Protocol

Use this sequence for complex multi-agent workflows:

```
1. Planner agent   → Analyze scope, gather context, output plan
2. Implementer     → Apply minimal code changes per plan
3. Security review → Inspect for shell/C/device safety regressions
4. CI triage       → Diagnose failing workflows, map to smallest fix
```

## 6. Safety & Compatibility Rules

### Secrets
- Never introduce tokens, passwords, API keys, or credentials
- Never commit `.env` files or key material

### Script Boundaries
- **Host scripts** (`nhctl`, `scripts/`, root `*.sh`): `#!/usr/bin/env bash` + `set -euo pipefail`
- **Device scripts** (`src/device/**`, `deploy/**/*.sh`): `#!/system/bin/sh` + POSIX-only
- **Plugins** (`plugins/nh-*`): Host-side Bash

### UX Stability
- Keep existing `nh-*` command names and output formats stable
- Prefer explicit errors (`die`) over silent fallbacks

### Quality
- All new code must pass `make lint` and `make test`
- All new device scripts must have a `PRIORITY:` declaration
- No generated artifact edits (`payload/`, `build/`, `dist/`)

## 8. Quick Reference

### Make Targets
```bash
make              # lint + build + stage + test
make lint         # Shell, C, JSON validation
make test         # BATS + C tests
make validate     # Full quality gate
make stage        # Stage payload/ from src/
make build        # Build C binaries + Magisk module
make deploy       # Stage + push to device
make clean        # Remove build artifacts
make dist         # Full distribution tarball
make opencode         # Start OpenCode agent session
make ai-cli-doctor    # Check AI tooling
make ai-context       # Repo context snapshot
make ai-bootstrap     # Workspace bootstrap
```

./nhctl deploy-tools        # Push tools to device

./nhctl ai status           # Device AI status
./nhctl ai diagnose         # Device AI diagnosis
./nhctl ai models           # Available AI models
./nhctl forward             # Setup ADB forwards
./nhctl setup-ssh           # Generate SSH config
